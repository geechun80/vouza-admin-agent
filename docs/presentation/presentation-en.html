01 · Overview

What is Admin Agent?

Admin Agent is an AI-powered office assistant that lives on your computer and works for you around the clock. It handles emails, schedules meetings, drafts replies, processes invoices, sends reports, and replies on WhatsApp — all while you focus on the work that matters.

💡 The Problem

Small business owners spend 3-5 hours every day on routine admin: sorting emails, scheduling meetings, sending follow-ups, processing expenses. This time should be spent on growing the business.

✨ The Solution

A personal AI employee that connects to your existing tools (Gmail, Calendar, WhatsApp) and handles routine tasks automatically — controlled by simple chat messages from your phone.

Your journey, end to end

From "never heard of it" to "couldn't live without it" — typically inside one week.

Day 0 · 5 minutes

Install & first launch

Download, run the installer, and open the dashboard at localhost:3456. Three install options: Docker, Windows one-click, or terminal.
Day 0 · 10 minutes

Setup wizard

Pick your AI provider (OpenAI, Anthropic, Google, OpenRouter), paste one key, and name your agent. The wizard handles everything else — no config files to edit.

Connect your channels

Connect Telegram (1 minute via @BotFather), WhatsApp (scan a QR code), Gmail (paste an App Password), Calendar (drop a service account JSON). Each connection is tested live before saving.
Day 1-2

First real conversations

Message your agent from your phone: "Summarize my unread emails", "Schedule a coffee with John next Tuesday", "Reply to Sarah that I'll send the proposal by Friday". Agent responds, takes action, confirms what it did.

Daily rhythm settles in

Morning briefing arrives automatically. Routine emails get triaged. Meeting requests get scheduled. You start asking for more: weekly reports, invoice processing, follow-up chains.

Customize and scale

07 · Intelligence

Smarter than typical chatbots

Four design choices make Admin Agent feel like a thoughtful assistant rather than a brittle script.

🧠 Multi-AI engine

Use any of 100+ AI models. Claude, GPT-4o, Gemini, DeepSeek — and switch transparently. If one provider has an outage, the agent automatically uses a backup.

🔄 Self-healing

Recovers from failures silently. If an action fails, the agent tries again with different methods before telling you. You only see real problems, not noise.

🎯 Context-aware

Remembers context across conversations. Each channel (WhatsApp, Telegram, Email) keeps its own conversation thread, so the agent knows who it's talking to and what about.

🛡️ Cost-controlled

Built-in spending guards. Daily budget caps prevent runaway API costs. You see exactly what's been spent and on what.

09 · Security & Privacy

Built for trust

Your business data is sensitive. Admin Agent is engineered with security as a first-class priority — not an afterthought.

  • ✓
    Loopback-only by default
    Dashboard is reachable only from your own computer. Cannot be accessed from your network or the internet unless you explicitly enable it (with password).
  • ✓
    Secrets never logged
    12 patterns of API keys and passwords are automatically redacted from any logs or memory before being stored.
  • ✓
    WhatsApp allowlist (deny by default)
    Only your own number can interact with the agent on WhatsApp. Add others explicitly. Friends messaging you won't get auto-responses.
  • ✓
    Sandboxed file operations
    The agent can only read/write files in a designated workspace folder. It cannot access your system files or other users' documents.
  • ✓
    PDPA-compliant audit log
    Every conversation is logged in a privacy-compliant format. Export your data, delete on request — full data sovereignty.
  • ✓
    Open source, transparent code
    All 22,000+ lines of code are auditable. 319 automated tests verify every behavior. Independent security review encouraged.
  • ✓
    Zero known vulnerabilities
    All dependencies regularly audited (latest: 28 May 2026, all clean). No known security flaws in shipped versions.
